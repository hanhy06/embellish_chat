# Mention Type

## Mention Types

* `EVERYONE`
    * Mentions **all players** on the server.
    * **Option:** `None`
* `INSIDE`
    * Mentions players **within a specific radius** around the sender (same world only).
    * **Option:** `Radius`
* `TEAM`
    * Mentions **all players in the specified team**.
    * **Option:** `Team Name`
* `PLAYER`
    * Mentions a **specific player** by name.
    * **Option:** `Player Name`
* `WORLD`
    * Mentions all players in a **specific world**.
    * **Option:** `World Name`
* `LUCK_PERMS_GROUP`
    * Mentions **all players in a specific LuckPerms group**. Requires LuckPerms to be installed.
    * **Option:** `Group Name`
* `CUSTOM`
    * Mentions all players matching the **vanilla target selectors**.
    * **Option:** `Target Selector`
